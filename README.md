\# LMS CI/CD Pipeline



This project implements an automated Jenkins CI/CD pipeline for an LMS application.



\## Features



\- Automated testing

\- LMS deployment

\- Deployment health checks

\- Success notifications

\- Failure notifications

\- Automatic rollback

\- Deployment backup



\## Pipeline Flow



GitHub

→ Jenkins

→ Automated Tests

→ Backup

→ Deployment

→ Health Check

→ Success / Rollback

→ Notification
